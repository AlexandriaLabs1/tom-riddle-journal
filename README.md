An interactive and atmospheric web application inspired by Tom Riddle's Diary from the *Harry Potter* universe, combined with modern AI. 🔮✨

## 🔑 Trigger Keywords & Phrases
The Diary responds dynamically based on specific context keywords in both **English** and **Russian**:
- **Greetings & Self-Introduction:** `hello`, `hi`, `who are you`, `greetings` / `привет`, `здравствуй`, `кто ты` 👋
- **User's Name Capture:** `my name is [Name]`, `i am [Name]` / `меня зовут [Имя]`, `моё имя [Имя]` 📝
- **Harry Potter Universe:** `harry`, `potter` / `гарри`, `поттер` ⚡
- **Hogwarts Lore:** `chamber`, `basilisk`, `secret` / `тайная комната`, `василиск` 🐍
- **Spells & Magic:** `spell`, `magic`, `lumos`, `avada` / `заклинание`, `магия`, `люмос`, `авада` 🪄

# 📖 Магический Дневник Тома Реддла

Интерактивное и атмосферное веб-приложение, вдохновленное Дневником Тома Реддла из вселенной *«Гарри Поттер»*, объединенное с современным ИИ. 🪄🔮

## 🔑 Ключевые слова и фразы
Дневник распознает ключевые темы и мгновенно меняет стиль ответов на **русском** и **английском** языках:
- **Приветствия и знакомство:** `привет`, `здравствуй`, `кто ты`, `hello`, `hi`, `who are you` 👋
- **Имя пользователя:** `меня зовут [Имя]`, `моё имя [Имя]`, `my name is [Name]`, `i am [Name]` 📝
- **Вселенная Гарри Поттера:** `гарри`, `поттер`, `harry`, `potter` ⚡
- **Тайны Хогвартса:** `тайная комната`, `василиск`, `chamber`, `basilisk` 🐍
- **Магия и заклинания:** `заклинание`, `магия`, `люмос`, `авада` 🪄
